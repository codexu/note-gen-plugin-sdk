# Embedded views example

Requires SDK 0.1.8 and a NoteGen development/release host implementing protocol 0.1.5. The numeric minimum application version is not a substitute for protocol compatibility.

Run the SDK CLI build/package commands from this directory, then install the resulting plugin in NoteGen. Open a new tab, a Markdown document, the files/records sidebar and the chat composer to see the declared locations. The status-bar view opens in a popover. Use the new-tab Customize menu to reorder or hide its panel, or the plugin settings page to hide an entire location.

This example uses no note permissions and displays only the host location. See [EMBEDDED-VIEWS.md](../../EMBEDDED-VIEWS.md) for lifecycle and stale-update handling.
