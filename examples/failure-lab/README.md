# 插件异常实验室

仅在隔离的桌面测试应用中使用。插件不读取文件、不访问网络，也不会在激活时自动触发故障。

```bash
node packages/plugin-cli/dist/bin.js build examples/failure-lab --app-version 0.37.0
```

通过开发者模式导入 `examples/failure-lab/.notegen/package`，启用并运行“打开异常实验室”。

- 普通异常：应显示错误，应用仍可响应操作。
- 死循环超时：应快速终止插件，关闭其视图，其他插件和宿主应继续工作。
- 内存超限：分配超出 32 MiB 沙箱限制的数组，应停止插件，应用和其他插件继续工作。
- 诊断日志：应在插件开发者页面看到三种日志级别，导出后包含错误堆栈。
- RPC 超额：65 个并发调用应触发配额错误，而非无限积压。

故障后检查插件管理页和日志，必要时先停用再启用。多次运行时崩溃可能使插件被隔离，这是预期保护；不要把本示例设为自动启动。
