# Resource pack sample

No JavaScript entry is required. From the SDK root use `pnpm exec notegen-plugin build examples/resource-pack` (see CLI help for installed command options). Import the generated development directory in NoteGen, enable it, then choose its theme or Français in interface settings. Only one French key is overridden; all other messages use built-in fallback. Icon rules are exact-path or extension matches. Disable/uninstall to remove contributions.
