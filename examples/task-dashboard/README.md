# Task Dashboard

开发示例，不会默认安装，也没有加入插件市场。要求包含分页与交互表格接口的 NoteGen 插件开发分支，API 版本保持 0.1.0。

在 SDK 根目录使用已构建的本地 CLI：

~~~sh
node packages/plugin-cli/dist/bin.js dev examples/task-dashboard
~~~

CLI 尚未构建时，先按 SDK 根目录说明准备本地开发工具。将生成的 examples/task-dashboard/.notegen/package 导入 NoteGen 开发者页面，执行“任务面板”命令。示例从工作区根目录查询，因此请使用独立的试用工作区，并授权根目录。

每次读取 25 篇笔记，在侧边栏显示 Markdown 未完成任务，并提供行内“完成”按钮。完成前重新读取笔记，校验修订号和原始行，再以 expectedRevision 写入；笔记被其他编辑器打开时，宿主会拒绝修改。示例不会自动关闭或强制保存笔记。

边界：

- 这是按笔记分页的面板，不是全库任务索引、日期查询或循环任务引擎。
- 每页最多展示 100 个任务，并限制内容体积；跳过超过 256 KiB 的文件。存在跳过内容时会显示提示。
- 识别基本的 Markdown 未完成任务并跳过围栏代码块，不实现完整 Markdown/Tasks 语法。
- 刷新从第一页开始。连续分页期间工作区文件发生增删或移动时，建议从头刷新；游标失效时不会自动循环重试。
- 已打开笔记的编辑事务和正文代码块渲染不是本示例提供的能力。

未在桌面宿主中验证前，不应把此示例当作完整的 Tasks 替代品。
